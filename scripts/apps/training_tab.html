Input Metrics & Feature Engineering
Electrodynamic Invariant Space v2_physics active
Eliminates collinear log-space redundancy by retiring ratio P / r (where log(P/r) = log P − log r) and replacing it with the normalized lateral gap clearance gnorm = (P − 2r)/P.
Scale Coordinates 3 dims
log(P), log(r), log(λ) [µm log-space]
Dielectric Permittivity 2 dims
ε₁ = n² − k², ε₂ = 2nk (dispersive gold)
Electrodynamic Ratios 2 dims
P/λ (Rayleigh anomaly), r/λ (retardation)
Lateral Gap Clearance Key Invariant
gnorm = (P − 2r)/P ∈ (0, 1]
Nominal 0.005 µm (5 nm) molecular/SAM spacer height for particle-on-mirror (NPoM) architectures. Adds feature column h_over_lambda.
Legacy v1 Feature Controls Deprecated
Legacy 5–8 input schema. Warning: includes collinear ratio P/r which is redundant with log(P) and log(r).
