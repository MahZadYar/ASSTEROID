Electrodynamic Invariant Space v3_physics active
Eliminates collinear log-space redundancy by retiring ratio P / r (where log(P/r) = log P − log r) and replacing it with the normalized lateral gap clearance gnorm = (P − 2r)/P.

P/λ (Rayleigh anomaly), r/λ (retardation)
Lateral Gap Clearance Key Invariant
ln gnorm = ln[(P − 2r)/P] — resolves the near-touching regime gnorm = (P − 2r)/P ∈ (0, 1]
Redundant for a fixed gap: hgap/λ is a constant multiple of 1/λ (a near-exact quadratic of ln λ). Kept only for reproducing v2 models.
Nominal 0.005 µm (5 nm) molecular/SAM spacer height for particle-on-mirror (NPoM) architectures. Adds feature column h_over_lambda.

Network Architecture
A λ-blind geometry encoder G(P, r) (sliceLayer of ln P, ln r, ln gnorm) multiplicatively gates a spectral-geometric residual stream: hk = hk−1 + Wo[ak ⊙ sk(G)]. Identity skips only; heads are physically bounded (sigmoid for Abs, softplus for log-EE).
Contracts multi-scale Block 2 features with direct coordinate/spectral basis modes via a rank-R multiplicative core for smooth 3D (p, r, λ) manifolds.
